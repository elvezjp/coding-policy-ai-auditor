# v0.5 修正計画書（2026-04-16）

## 目的

Windows 環境での静的解析モジュールの動作不具合（Issue #13）およびフロントエンドテストの不安定性（Issue #15）を修正し、v0.5 としてリリースする。

## 対象 Issue / PR

| 番号 | タイトル | 種別 |
|------|---------|------|
| [Issue #13](https://github.com/elvezjp/coding-policy-ai-auditor/issues/13) | Windows対応: 静的解析モジュールの .bat/.cmd 実行・エンコーディング問題 | bug |
| [Issue #15](https://github.com/elvezjp/coding-policy-ai-auditor/issues/15) | フロントエンドテスト失敗: addCodeFiles でファイル再選択時に既存ファイルがリセットされない | bug |
| [PR #14](https://github.com/elvezjp/coding-policy-ai-auditor/pull/14) | Windows対応の実装（Issue #13 の改修案） | PR |

## 前提・経緯

- PR #14（atsutakaGithub 氏による改修案）は `versions/v0.4` に対して実装されていた
- 本件対応として、v0.4 を変更せず新たに `versions/v0.5` ディレクトリを作成して管理する方針とした
- PR #14 のブランチ `takahashi/20260331-issue-13-windows` 上で作業を行い、以下を実施済み:
  1. `versions/v0.4` → `versions/v0.5` にリネーム（`git mv`）
  2. `main` ブランチからオリジナルの `versions/v0.4` を復元
  3. `versions/v0.5` 内のバージョン番号を v0.4.0 → v0.5.0 に一括更新

## 仕様書（spec.md）の修正箇所

仕様駆動開発の工程に従い、実装に先立って仕様書を更新する。

### S-1: F-05 機能詳細にWindows対応・エンコーディング仕様を追記（L132-139）

現状の F-05 にはツール名と実行タイミングしか記載がなく、Windows での実行方式やエンコーディング処理について言及がない。

**現状:**
```
| 項目 | 内容 |
|------|------|
| Java用ツール | Checkstyle, PMD |
| Python用ツール | Ruff, Flake8, Pylint |
| 実行タイミング | AI監査前（オプション） |
| 結果連携 | 静的解析サマリーをLLMコンテキストに含める |
```

**追記内容:**

| 項目 | 追記内容 |
|------|---------|
| Windows対応 | `.bat/.cmd` 形式のツールを `cmd /c` 経由で安全に実行（`shell=True` 不使用） |
| エンコーディング | ツール出力を UTF-8 → CP932 → デフォルト → replace の順でフォールバックデコード |
| ファイルエンコーディング変換 | 解析対象ファイルが CP932 の場合、一時ファイルに UTF-8 で書き戻してからツールに渡す |

### S-2: F-01 機能詳細にファイル再選択時の動作を明記（L60-67）

現状の F-01 にはファイル再選択時の振る舞いが未定義。Issue #15 で発覚した通り、再選択時に既存ファイルがリセットされるべきかどうかの仕様が必要。

**追記内容:**

| 項目 | 追記内容 |
|------|---------|
| ファイル再選択 | プログラムファイルを再選択した場合、既存のファイル一覧を新しい選択結果で置換する |

### S-3: 8.2 前提条件の Python バージョンを修正（L811）

現状は「Python 3.10以上」と記載されているが、`pyproject.toml` の `requires-python = ">=3.11"` と不整合。

**修正:**
- 現状: `Python 3.10以上がインストールされていること`
- 修正後: `Python 3.11以上がインストールされていること`

### S-4: 8.2 前提条件に Windows 動作環境の記載を追加（L808-813）

v0.5 で Windows 対応を行うため、対応 OS を明記する。

**追記内容:**

| 項目 | 追記内容 |
|------|---------|
| 対応OS | macOS, Linux, Windows（Windows では静的解析ツールが `.bat/.cmd` 形式で提供される場合がある） |
